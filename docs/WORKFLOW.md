# WORKFLOW.md

## Назначение

Этот файл фиксирует текущий рабочий процесс разработки в DEV-среде для Telegram-бота.

Цель:
- быстро тестировать изменения
- не трогать PROD во время разработки
- не делать ручную грязную работу через БД
- использовать единый понятный сценарий работы

---

## 1. Где работаем

Рабочая DEV-среда:

- проект: `~/telegram_bot-dev`
- env: `.env.dev`
- БД: `botdb_dev`
- бот: отдельный DEV-бот
- DEV-режим: `DEV_MODE=true`

Важно:
- DEV не должен ломать PROD
- DEV не должен использовать PROD БД
- DEV не должен зависеть от панели для тестовых ключей

---
